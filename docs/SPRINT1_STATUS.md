# Local experiment scope

This local checkout retains US1.1 (registration, login and sessions) and US1.2
(admin roles, account management and audit records).

Profile editing, public profiles, culinary preferences, recipe authoring and the
personal recipe library have been removed from the implementation. Their original
files remain empty. Shared models, schemas, API clients, navigation, migrations,
styles and tests have been reduced to account and admin functionality.

The full sprint plan, specification and intent documents are retained as reference;
they do not describe the implemented scope of this trimmed local experiment.

This trimmed implementation is isolated on the codex/accounts-admin-only branch.
